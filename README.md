# CuadraStock Inventario Simple

Crea una landing page en español para un servicio web llamado "CuadraStock", que permite a negocios minoristas del Perú (bodegas, ferreterías, boticas, tiendas de ropa) generar su propio sistema personalizado de gestión de inventario, sin saber programar.

OBJETIVO DE LA PÁGINA

Que el visitante entienda en segundos qué ofrecemos y presione el botón principal para iniciar el servicio.

ESTRUCTURA (en este orden)

1. Navbar: logo, enlaces (Cómo funciona, Beneficios, Contacto) y botón "Iniciar sesión con Google".

2. Hero: título fuerte, subtítulo de una línea, botón principal grande "Crear mi sistema de inventario" y una imagen o mockup de un panel de inventario.

3. Problema: 3 tarjetas con los dolores del minorista (stock desordenado, pérdidas por falta de control, ventas sin registro).

4. Cómo funciona: 3 pasos con íconos (1. Inicia sesión con Google, 2. Personaliza tu inventario, 3. Empieza a controlar tu stock).

5. Beneficios: alertas de stock bajo, importación desde Excel, atributos personalizados por producto, acceso desde celular y PC.

6. Sección final con llamado a la acción y el mismo botón principal.

7. Footer simple con contacto y derechos reservados.

DISEÑO

- Estilo moderno, limpio y profesional, con mucho espacio en blanco.

- Paleta: azul como color principal, verde como acento para los botones de acción, fondo claro.

- Tipografía sans-serif legible (Inter o similar).

- Esquinas redondeadas, sombras suaves, animaciones sutiles al hacer scroll.

- Totalmente responsive (móvil primero).

GENERA 3 VARIANTES

- Variante A: minimalista y corporativa.

- Variante B: colorida y amigable para pequeños comerciantes.

- Variante C: oscura (dark mode) y tecnológica.

Usa React + Tailwind CSS. Todo el texto en español peruano, tono cercano y claro. Usa datos de ejemplo, sin lorem ipsum.
